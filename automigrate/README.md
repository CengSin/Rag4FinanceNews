# Payload (元数据) 结构设计

Payload 是存储在向量旁边的 JSON 数据，用于 RAG 的上下文检索和过滤。

| 字段名          |    类型 (Go) | Qdrant 类型 | 索引类型 (Index) | 用途说明                                      |
|--------------|-----------:|-----------|:------------:|-------------------------------------------|
| `article_id` |   `string` | Keyword   |      ✅       | 唯一标识，用于去重或更新。                             |
| `column_id`  |   `string` | Keyword   |      ✅       | 核心字段。用于过滤用户已购买/未购买的栏目。                    |
| `title`      |   `string` | Text      |      ❌       | 用于展示和做简单的关键词匹配（如需要）。                      |
| `summary`    |   `string` | Text      |      ❌       | RAG 核心。LLM 生成的摘要，检索后直接喂给 LLM 做推荐理由，避免存全文。 |
| `tags`       | `[]string` | Keyword   |      ✅       | 金融标签（如 `半导体`、`美联储`、`A股`），用于精确筛选。          |
| `publish_ts` |    `int64` | Integer   |      ✅       | Unix 时间戳，用于按时间范围过滤（如 `只看最近3天`）。           |
